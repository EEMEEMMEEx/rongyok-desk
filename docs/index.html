Rongyok Desk — rongyok.com

Built for Focus

Desktop-native behavior without browser tab clutter

Every detail in rongyok-ssb is implemented in Rust and Tauri v2 (wry) to keep Rongyok responsive, isolated, and ready for media playback.

Strict Domain Isolation

Allows only https:// and http:// navigation for rongyok.com and *.rongyok.com (plus internal about:, data:, and blob: webview URLs). Lookalike hosts and external schemes like mailto:, tel:, and file: are blocked from hijacking the window.

External Link Handoff

Non-Rongyok links and external target="_blank" pop-ups open automatically in your system default browser (ShellExecuteW on Windows, open on macOS, xdg-open on Linux), while same-site pop-ups stay inside the app window.

Persistent Session & Cookies

Webview storage and cookies persist across launches in your local app data directory (<app_local_data_dir>/webview, or ~/.var/app/com.rongyok.ssb on Flatpak), keeping your login and watch state intact.

Remembered Window Placement

Saves window coordinates, size (default 1280×800, min 520×400), and maximized state in window-placement.txt. Validates against connected monitors on startup and re-centers safely if a display was unplugged.

HTML5 Media & Fullscreen

Configures --autoplay-policy=no-user-gesture-required and disables background throttling for uninterrupted playback. Syncs HTML5 video fullscreen on Windows WebView2 and enables PulseAudio and DRI hardware rendering in Flatpak.

Shortcuts & Diagnostics

Capture-phase keyboard listeners ensure navigation shortcuts work even when page scripts intercept keys. DevTools are disabled in production builds, and Windows includes a non-focused --screenshot <file.png> diagnostic CLI flag.

Setup Steps

Installation Instructions by OS

Choose your operating system below for verified installation steps and first-launch notes for unsigned v1.0.2 builds.

  1. Choose your installer package: Use Rongyok.Desk_1.0.2_x64-setup.exe (recommended per-user installer) or Rongyok.Desk_1.0.2_x64_en-US.msi.
  2. Run the installer: The NSIS .exe installer automatically downloads Microsoft Edge WebView2 Runtime if it is not yet installed on your PC.
  3. First-launch SmartScreen prompt: Because v1.0.2 binaries are unsigned, Windows SmartScreen may warn on first run. Click More info and then Run anyway.
  1. Download the matching disk image: Choose Rongyok.Desk_1.0.2_aarch64.dmg for Apple Silicon (M1–M4) or Rongyok.Desk_1.0.2_x64.dmg for Intel Macs (macOS 10.15+).
  2. Install to Applications: Open the .dmg file and drag Rongyok Desk.app into your Applications folder.
  3. First-launch Gatekeeper approval: Because the app bundle is unsigned, Right-click (or Control-click) Rongyok Desk.app → Open → Open (or open System Settings → Privacy & Security → Open Anyway).
  1. Ensure Flathub is configured (required to provide org.gnome.Platform//49): 
    flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
  2. Install the downloaded Flatpak bundle (Rongyok-Desk-1.0.2-x86_64.flatpak): 
    flatpak install --user Rongyok-Desk-1.0.2-x86_64.flatpak
  3. Launch Rongyok Desk from your desktop application menu or run: 
    flatpak run com.rongyok.ssb
